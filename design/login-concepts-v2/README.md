# NEXUS — Login Redesign V2 (5 conceitos novos)

Segunda ronda, mais ousada/criativa. Mockups de alta-fidelidade (HTML/CSS reais, renderizados no browser).
Abre `index.html` para ver os 5 lado a lado. PNGs prontos a partilhar.

Todos cumprem os requisitos: **e-mail, senha (mostrar/ocultar), "lembrar-me", "esqueci a senha", login social (Google/Apple) e CTA de cadastro.**

| # | Conceito | Direção | Tipografia |
|---|---|---|---|
| 1 | **Nebula** | Aurora mesh gradient + cartão glass fosco. Vibrante, criativo. | Space Grotesk + Inter |
| 2 | **Bento** | Grelha modular com o produto vivo (ofensiva/XP/hábitos/gráfico) + form. | Syne + DM Sans |
| 3 | **Spatial** | Profundidade tipo visionOS, painéis a flutuar em camadas 3D. | Inter + Syne |
| 4 | **Editorial** | Tipografia gigante estilo revista, inputs underline, assimétrico. | Syne + Inter |
| 5 | **Pulse** | Herói gamificado: anel de XP com chama, nível e consistência. | Syne + DM Sans |

## Recomendação
Para a NEXUS (hábitos/evolução, brand dourado-escuro, gamificado):
1. **Pulse** ou **Bento** — comunicam o valor/gamificação do produto logo no login → maior pull emocional e conversão, mantendo o brand.
2. **Nebula** — se quiseres um salto visual mais "wow" e moderno.
3. **Editorial** / **Spatial** — fortes para landing/marketing e momentos premium.

Sugestão: **Bento** como tela principal (mostra o produto) + acento **Pulse** (anel de ofensiva) no estado "voltar a entrar".
