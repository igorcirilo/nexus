# NEXUS — Login como Assistente Pessoal (4 modelos)

Logins que apresentam a NEXUS como **assistente pessoal**, com amostras reais do produto ao lado do formulário.
Mockups de alta-fidelidade (HTML/CSS reais). Abre `index.html` para ver os 4. PNGs prontos a partilhar.

Requisitos mantidos: **e-mail, senha (mostrar/ocultar), "lembrar-me", "esqueci a senha", login social (Google/Apple) e cadastro.**

| # | Modelo | Amostra do produto | Accent |
|---|---|---|---|
| 1 | **Aria** | Conversa do assistente: saudação, resumo do dia, plano e sugestões acionáveis. | Dourado |
| 2 | **Orbit** | Mockup real do app ("Hoje") + pills de funcionalidades + bolha do assistente. | Dourado/roxo |
| 3 | **Briefing** | Timeline/agenda do dia que o assistente prepara (4 momentos com horários). | Teal |
| 4 | **Lumen** | Versão clara premium: saudação + 3 cartões de funcionalidades. | Dourado/preto |

## Recomendação
- **Orbit** vende melhor o produto (mostra a app a funcionar) → forte para novos utilizadores.
- **Aria** comunica a proposta "assistente" de forma mais imediata e emocional.
- **Briefing** transmite organização/calma; **Lumen** é o mais sóbrio/profissional (e o único claro).

Para mobile (acesso principal), o painel de amostra vira um **carrossel de introdução** acima do form (ou é ocultável), mantendo e-mail/senha/CTA acima da dobra.
