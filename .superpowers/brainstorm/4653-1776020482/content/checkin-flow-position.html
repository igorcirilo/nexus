Onde entra a revisão de tasks no check-in noturno?

O check-in noturno hoje tem: missão concluída? → vitória do dia → humor → reflexão (opcional). Em qual ponto entram as tasks?

A

Primeiro passo — antes de tudo

Revisão de tasks abre o check-in noturno. O usuário confirma cada task antes de responder as perguntas de reflexão.

✅ Tasks do dia → Missão concluída? → Vitória → Humor → Reflexão
B

Último passo — antes de fechar

O usuário responde as perguntas normais e, no final, vê o resumo das tasks + confirma o fechamento do dia.

Missão concluída? → Vitória → Humor → Reflexão → ✅ Resumo de tasks
C

Integrado — substitui "missão concluída?"

A tela de tasks é a pergunta de conclusão. As tasks substituem o campo "missão concluída?" por uma view mais rica.

✅ Tasks + missão → Vitória → Humor → Reflexão
